# MIA – Mock Interview Agent

Mock Interview Agent (MIA) – practice interviews with AI feedback.

## Project structure

- **`frontend/`** – React + Vite UI (dev, build, tests)
- **`backend/`** – Backend API (to be implemented)

## Getting started

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Build: `npm run build`  
Preview: `npm run preview`  
Tests: `npm run test`

### Backend

See `backend/README.md`. Backend is planned for future implementation.
